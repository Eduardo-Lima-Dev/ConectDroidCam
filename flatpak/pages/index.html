ConectDroidCam

Use a câmera do celular como webcam no Linux.

Instalar com atualizações automáticas

Cadastre o repositório uma vez e instale. Depois, as versões novas chegam pelo flatpak update e pela loja do sistema (GNOME Software, Discover).

flatpak remote-add --user --if-not-exists conectdroidcam https://eduardo-lima-dev.github.io/ConectDroidCam/conectdroidcam.flatpakrepo
flatpak install --user conectdroidcam io.github.eduardo_lima_dev.ConectDroidCam

Ou abra o arquivo io.github.eduardo_lima_dev.ConectDroidCam.flatpakref na loja do sistema.

Webcam virtual

A imagem aparece como webcam por meio do módulo v4l2loopback do Linux, que precisa ser instalado no sistema uma vez. O app mostra o comando quando ele faltar.

Celular Android

Baixe o APK da página de releases. Depois de instalado, o próprio app avisa quando há versão nova.
